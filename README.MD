# Retro Music Player 

A simple retro-style music player built with HTML, CSS, and JavaScript.

##  What it does
This is a web-based music player that lets you play, pause, and skip tracks with a retro-themed UI.

## Features
- Play / pause music
- Next / previous track controls
- Clean retro interface
- Lightweight and fast
- Works in the browser (no install needed)

## Built With
- HTML
- CSS
- JavaScript

##  How to Run
1. Download or clone the repo  
2. Open `index.html` in your browser  
3. Hit play and enjoy

##  Future Ideas
- Volume control
- Shuffle / repeat mode
- Playlist system
- Improved animations

## Note
Built as a beginner-friendly project to practice front-end development and audio handling in JavaScript.
